Install it

These steps are for Chrome on Android. Other browsers ask the same things in their own words.

  1. Tap the button above. If Chrome warns that the file might be harmful, tap Download anyway.
  2. Open the downloaded file from the notification, or from Downloads in Chrome's menu.
  3. If Android says your phone isn't allowed to install unknown apps from this source, tap Settings, turn on Allow from this source for Chrome, then go back.
  4. Tap Install. Google Play Protect may show a warning, because this copy didn't come from Google Play. Tap More details, then Install anyway, only if you got the file from this page.

Moving to Google Play later

GhostWord is on its way to Google Play. When it's there, you can install it from Play. If Play says it can't install GhostWord over this copy, uninstall this copy first, then install from Play. Uninstalling deletes your History, because it lives only on your phone.

Private by default

No account, no ads and no analytics. GhostWord works offline and keeps your questions, picks and history on your phone.
